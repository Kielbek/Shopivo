# Sekcje wspólne

Sekcje z tego folderu są dostępne w każdym szablonie v2 (np. odliczanie do dropu, baner kampanii).

- **Dopasowanie do szablonu.** Sekcje biorą wygląd ze zmiennych CSS `--shop-*` (`shared.css`). Szablon dopasowuje je, ustawiając te zmienne w swoim CSS.
- **Własna wersja sekcji.** Szablon może mieć własną wersję sekcji: plik o tej samej nazwie w `sections/` szablonu ma pierwszeństwo.
- **Snippety.** Nazwy snippetów zaczynają się od `shop-`, żeby nie kolidowały ze snippetami szablonów.
